LENY GRACE LITAN — ONLINE PORTFOLIO

CONTENTS
- index.html: portfolio website
- styles.css: responsive styling
- script.js: mobile navigation and KPI tabs
- assets/leny-headshot.png: refreshed professional-style headshot
- assets/Leny_Grace_Litan_Resume.pdf: downloadable resume

PREVIEW
1. Extract the ZIP.
2. Open index.html in your browser.
3. Keep the assets folder beside index.html.

PUBLISH FREE WITH GITHUB PAGES
1. Sign in or create an account at https://github.com/
2. Create a public repository named leny-grace-litan-portfolio.
3. Upload index.html, styles.css, script.js, README.txt, and the whole assets folder.
4. Open repository Settings → Pages.
5. Under Build and deployment choose “Deploy from a branch”.
6. Select branch “main” and folder “/(root)”, then Save.
7. When published, your site URL will look like:
   https://YOUR-GITHUB-USERNAME.github.io/leny-grace-litan-portfolio/
   Replace YOUR-GITHUB-USERNAME with your GitHub username.

REVIEW BEFORE PUBLISHING
- This package creates the files but does not publish them automatically.
- KPIs are presented as targets/measurement criteria, not achieved results.
- Your email, phone, and location are public on the site; remove details you do not want online.
- Confirm the generated professional headshot looks like you before publishing.
- Google Fonts requires internet access; fallback fonts will be used otherwise.
